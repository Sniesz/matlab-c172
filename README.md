# matlab-c172
Using MATLAB analysis of aerodynamic equations to show the perference of Cessna 172 aircraft.
## Overview
This project will model basic perferences across a set range of airspeeds using standard aerodynamic equations. It examines lift, drag, LD ratio, stall speed, and effects of changing parameters. All parameters were specific selected based on Cessna 172 Skyhack specifications for realistic data and will be changed for any purpose of the analysis.
## Objectives
- Calculate Lift-Drag across many airspeeds
- Visualise induced and parasite drag
- Effects of changing air density
